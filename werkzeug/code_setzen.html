Neuen Zugangscode setzen

Wenn der alte Code weg ist. Drei Schritte, nichts zu tippen.

Der Code entsteht hier in deinem Browser und verlaesst ihn nicht. Er wird nirgendwohin geschickt, weder an mich noch an einen Server. Nur du siehst ihn. Schreib ihn dorthin, wo deine anderen Passwoerter liegen, BEVOR du diese Seite zumachst: danach ist er nicht mehr abrufbar.
SCHRITT 1

Dein neuer Code

Achtzehn Zeichen aus dem Zufallsgenerator deines Browsers, davon zwoelf zufaellige. Aehnlich aussehende Zeichen wie 0 und O oder 1 und I kommen nicht vor, damit du dich beim Abtippen nicht vertust.

wird gewuerfelt ...

SCHRITT 2

Den Befehl in Supabase ausfuehren

Der Knopf unten oeffnet den SQL-Editor deines Projekts appload in einem neuen Fenster. Dort den Befehl einfuegen und auf Run druecken. Es muss UPDATE 1 zurueckkommen.

wird gebaut ...
SQL-Editor oeffnen

Achtung: in diesem Befehl steht dein neuer Code im Klartext. Fuege ihn nur im SQL-Editor ein, sonst nirgends.

SCHRITT 3

Hinein

Zurueck ins Programm und mit dem neuen Code anmelden.

Kombi Exchange oeffnen

Kommt in Supabase UPDATE 0 statt UPDATE 1 zurueck, gibt es keine aktive Codezeile. Dann ist es ein anderer Fall, siehe NOTFALL.md.
